# Compliance checklist

Tracks the pinned decisions (CLAUDE.md) and the §5.7 security design against
what is actually built. "Built" means there is code and a test; "Pending" means
the sprint has not landed yet. Nothing is marked built on intention alone.

## Pinned decisions

| Decision | State | Where |
|---|---|---|
| Fall confirmation 10 s; response window 60 s from `questionSentAt` (server time) | Built (config) | `FALL_CONFIRM_SEC` / `RESPONSE_WINDOW_SEC` in `apps/api/src/config.ts`; locked fields in `packages/contracts/src/device.ts`; `config.ts` warns if they drift |
| SMS is sent only by the bike; the backend never sends SMS | Held | No SMS provider is a dependency of `apps/api`; nothing in the codebase sends one |
| Device transport HTTP + HMAC under `/d/v1`; app API under `/api/v1` | Partly built | `/api/v1` built; `/d/v1` pending (device gateway sprint) |
| Device auth is query-string based (Appendix E.1.2, not headers) | Built (signing) | `apps/api/src/lib/hmac.ts`, `test/hmac.test.ts`, `tools/device-sim vector` |
| GPRS / camera / upload already proven — no SMS-only primary path | Held | No fallback design added |
| No FCM in the MVP (M7) | Held | `firebase-admin` is not a dependency; `PushPayloadSchema` exists as a contract only |
| Battery percent never measured (M10) | Built | `DeviceHealthSchema.batteryV` is `z.null()`; `buildHealthDto` forces null |
| No password reset in the MVP (M11) | Held | `/auth/password/*` deliberately not implemented; documented in `modules/auth/routes.ts` |
| Node 20, Fastify, TS strict, Prisma 6 (not 7), Postgres 16 | Built | `apps/api/package.json` pins `prisma@^6.19`; CI uses Node 20 and `postgres:16-alpine` |
| Shared zod schemas in `packages/contracts`; never duplicate enums | Built | Every enum is declared once in `packages/contracts/src/enums.ts` |
| Incident id == device eventId; decisions row-locked (D1–D10) | Pending | `Incident.id` has no default in the schema (device eventId); the decision engine is a later sprint |
| Honest UI: labels start with "Possible"; never claim unproven delivery | Held | Appendix D labels in `packages/contracts/src/common.ts`; seed records SMS only as `AT_SUBMITTED` |

## Security design (§5.7)

| Control | State | Where |
|---|---|---|
| bcrypt cost 10 password hashes | Built | `modules/auth/service.ts`; asserted in `test/auth.test.ts` |
| JWT HS256 access token, 1 h, claims `sub`/`role`/`isDemo` | Built | `plugins/auth.ts` |
| Opaque refresh token, SHA-256 at rest, 30 d, rotated, revocable | Built | `modules/auth/service.ts`; `test/auth.test.ts` |
| Login throttling 10/min per IP | Built | `routeRateLimit` on `/auth/login` (disabled under test) |
| Failed-login lockout (5 per account / 15 min) | Pending | §5.4.10 also asks for a per-account counter |
| Device secrets encrypted at rest (AES-256-GCM) | Built | `lib/crypto.ts`; asserted in `test/ownership.test.ts` |
| Pairing codes hashed, not stored in the clear | Built | `modules/admin/provisioning.ts`; asserted in `test/ownership.test.ts` |
| Ownership scoping returns 404, never 403 | Built | `lib/ownership.ts`; asserted in `test/ownership.test.ts` |
| Guest tokens rejected on all non-GET routes | Built | Global `preHandler` in `plugins/auth.ts`; asserted in `test/ownership.test.ts` |
| Phone numbers masked in logs, lists and driver-facing views | Built | `lib/mask.ts`, pino `logMethod` hook in `app.ts`; asserted in `test/ownership.test.ts` |
| Consent recorded (`users.consent_at`) | Built | `modules/auth/service.ts` |
| Audit events for login, rental assign/end/force-activate, provision/revoke, pairing | Partly built | Rentals, pairing, provisioning and revoke are audited; login is not yet |
| Error codes restricted to the §5.4.1 table | Built | `ERROR_CODES` / `ERROR_STATUS` in contracts; `AppError` cannot express anything else |
| Signed file URLs, image integrity, retention jobs | Pending | Images and workers are later sprints |
| TLS 1.2+, HSTS, `client_max_body_size 32k` on `/d/` | Configured | `deploy/nginx/crashlink.conf` |

## Data protection

- Secrets live only in `.env` on the VPS (`chmod 600`); `.env.example` is the
  only committed copy and holds no values.
- `firmware/**/include/secrets.h` is gitignored and regenerated by the seed or
  the provisioning CLI.
- Device secrets are shown exactly once and cannot be read back.
