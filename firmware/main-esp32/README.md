# main-esp32 (PlatformIO)

Scaffold only. The firmware is built against Appendix E and **Appendix E.1**,
which records what the team has already proven on hardware and overrides §5.3
where they differ:

- Request auth goes in the **query string** (`?dev=&ts=&nonce=&sig=`), not in
  headers (E.1.2). Canonical string:
  `METHOD \n path \n dev \n ts \n nonce \n sha256hex(body)`, `path` without the query.
- Verify the signature against `npm run sim -w tools/device-sim -- vector`
  before touching the modem.
- Read the response body (`AT+HTTPREAD`) - every response carries queued commands (E.1.3).
- Keep the GPRS bearer open; never block the sensor loop (E.1.4).
- Cap image uploads at 10 KB at 9600 baud (E.1.5).

`include/secrets.h` is generated by `npm run db:seed -w apps/api` or
`npm run device:provision -w apps/api` and is **gitignored**.
